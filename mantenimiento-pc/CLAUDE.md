## Tareas de mantenimiento

### 1. Limpieza periódica
- Archivos temporales (C:\Windows\Temp, %TEMP%)
- Papelera de reciclaje
- Caché del navegador
- Archivos de instalación antiguos

### 2. Chequeo de espacio en SSD (C:)
- Alerta si el espacio libre baja de un umbral (ej. menos de 20GB libres)
- Identificar carpetas que más ocupan

### 3. Actualizaciones
- Verificar actualizaciones pendientes de Windows
- Verificar actualizaciones de Python y paquetes instalados

### 4. Monitoreo de fallas
- Revisar Event Viewer (errores críticos y advertencias recientes)
- Estado del SSD y HDD (S.M.A.R.T.)

### 5. Revisión de espías / seguridad
- Programas en el arranque (detectar entradas sospechosas)
- Procesos activos inusuales
- Conexiones de red activas sospechosas
- Windows Defender: verificar que esté activo y actualizado
