# Datos Técnicos de Libros

## Descripción
A partir de un listado de ISBNs, buscar en la web los datos técnicos de cada libro.

## Estado
Proyecto en definición. Pendiente de especificar:
- Qué datos técnicos se necesitan (título, autor, editorial, año, páginas, etc.)
- Formato del listado de entrada (Excel, texto, etc.)
- Formato del resultado esperado
- Fuentes de búsqueda preferidas (Google Books, OpenLibrary, etc.)
